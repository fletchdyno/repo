🔐 Electrum-FIRO Wallet
=======================

Welcome to **Electrum-FIRO**, the lightweight and privacy-enhanced wallet designed for **Firo (formerly Zcoin)** users. This wallet is tailored for secure and anonymous cryptocurrency transactions without sacrificing usability or speed.

* * *

Why Electrum-FIRO?
------------------

* 🚀 Fast startup with no full blockchain sync
    
* 🛡️ Enhanced privacy and anonymity features
    
* 🖥️ Supports Windows, macOS, and Linux
    
* 🔄 Compatible with hardware wallets
    
* 👐 Fully open-source and community audited

🔒 Security Best Practices
--------------------------

* Verify downloads using PGP signatures or checksums
    
* Keep your seed phrase secure and offline
    
* Use hardware wallets to maximize security
